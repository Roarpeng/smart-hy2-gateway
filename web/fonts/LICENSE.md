# Switzer

The console self-hosts Switzer so the UI keeps its typography when the gateway is
offline or the WAN is down.

- Source: https://www.fontshare.com/fonts/switzer
- Weights included: 400, 500, 600 (WOFF2)
- License: Fontshare free font license, free for personal and commercial use.
  See the license published with the font: https://www.fontshare.com/licenses/itf-ffl

The WOFF2 files are redistributed unmodified. Latin glyphs use Switzer; Chinese
glyphs fall back to the host's system CJK font (Noto Sans CJK SC, PingFang SC,
or Microsoft YaHei).
