运维速查

在宿主机执行。排障时先看分流日志，再确认规则状态。

journalctl -f -t HY2_DISPATCH -t HY2_PROXY   # 实时决策日志
/usr/local/bin/proxy-switch.sh status         # 查看规则状态
sudo /usr/local/bin/proxy-switch.sh off       # 一键恢复直连
curl -s http://127.0.0.1:8080/api/status      # 后端健康快照

继续排查

节点握手失败时，先测延迟，再检查 SNI、混淆口令与端口跳跃范围。切换与编辑都在节点管理里完成。
